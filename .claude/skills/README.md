# Project skills

The skills the agents use in this repo. `AGENTS.md` says when to use each one.

| Skill | What it does | Source |
|---|---|---|
| `stop-slop` | Removes the patterns that make prose sound machine written | github.com/hardikpandya/stop-slop at commit 8da1f03, MIT licence (see its LICENSE) |

To update a skill, copy the new version over its folder and change the commit above. Never leave a `.git` folder inside a skill: git would treat it as a separate repository and skip the files.
